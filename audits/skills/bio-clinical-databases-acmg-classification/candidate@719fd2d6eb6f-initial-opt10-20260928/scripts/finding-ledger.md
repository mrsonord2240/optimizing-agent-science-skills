# Ordered finding ledger

1. **ACMG-001 — P0 — OddsPath evidence strengths are shifted and incomplete.** The helper promotes `>4.3` to PS3 Strong instead of Moderate, `>2.1` to Moderate instead of Supporting, invents a `>1.2` pathogenic supporting band, misplaces the benign mirrors, and never represents PS3 Very Strong above 350. The reference table also labels `>18.7` Very Strong instead of Strong.
2. **ACMG-002 — P0 — The PVS1 sketch can apply PVS1 to a disease-irrelevant transcript and shortcut splice interpretation.** `is_alt_isoform_in_disease_tissue` is accepted but ignored, so a declared irrelevant transcript still returns PVS1 Very Strong. Canonical splice calls do not require predicted/observed transcript consequence, rescue-transcript review, or the LoF-mechanism prerequisite in the callable contract.
3. **ACMG-003 — P0 — AlphaMissense behavior contradicts the advertised 2025 calibration.** The description promises Bergquist-calibrated graded PP3/BP4 thresholds, while the helper uses uncited 0.2/0.7 supporting-only cutoffs. It assigns evidence inside the calibrated indeterminate interval and cannot return higher calibrated strengths.
4. **ACMG-004 — P1 — The shipped GeneBe helper uses a stale request contract.** It sends HGVS in `variant=` and receives HTTP 400; the current documented GET requires `chr`, `pos`, `ref`, `alt`, and `genome`, which returned HTTP 200 in the control.
5. **ACMG-005 — P1 — The authoritative CSpec route is stale.** The supplied `/cspec/ui/svi/all` GET returns HTTP 400. Current REST service and versioned gene endpoints return structured JSON and must replace the stale route with an access-date/version workflow.
6. **ACMG-006 — P1 — Evidence and numerical inputs are not validated.** Unknown criteria are silently scored as zero, duplicates are counted twice, out-of-range predictor values and negative OddsPath/prevalence are accepted, zero penetrance crashes, and a negative OncoKB level is promoted to Tier II-C.
7. **ACMG-007 — P1 — The default demonstration combines discordant computational evidence without reconciliation.** It sums REVEL PP3 Strong and SpliceAI BP4 Supporting alongside the misweighted PS3 result and prints a precise Likely Pathogenic classification without transcript, disease-mechanism, VCEP, assay-validity, conflict, or uncertainty context.
8. **ACMG-008 — P1 — Direct clinical classification lacks a practice-boundary guard.** Neither the skill nor script requires qualified clinical review or clearly states that the helpers are educational sketches unsuitable for patient diagnosis or treatment decisions; the executable emits definitive category labels.
9. **ACMG-009 — P2 — The somatic helper collapses Tier III and Tier IV.** It cannot distinguish VUS-somatic from benign-somatic and relies on a loose numeric OncoKB surrogate rather than explicit evidence-level validation and current knowledgebase provenance.
