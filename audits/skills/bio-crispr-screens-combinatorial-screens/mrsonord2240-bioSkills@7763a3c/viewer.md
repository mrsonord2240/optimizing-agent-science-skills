## Judgment call on the 2 disputed P2s (fixer asked the re-auditor to confirm)

The fixer left 2 P2s open, judging both "new statistical guidance" and therefore out of a fixer's
scope. Re-auditor's independent assessment, applying FIX_BRIEF's own bar ("method-level changes are
allowed only when the audit demonstrated the problem with a run"):

- **"No minimum-N guidance for the z-score cutoff" (Input 3) -- disagree with leaving it open.**
  Independently reproduced on a fresh 9-pair dataset (seed 55221, distinct from the original audit's
  8-pair set): 2 planted strong synthetic-lethal pairs (gi_z = -1.71, -1.85) were the two most extreme
  values by raw effect size but still failed to cross the documented z<-2 cutoff, purely because N=9
  underpowers the null distribution (script: `run/reaudit_smalln.py`). This is exactly the class of
  evidence FIX_BRIEF requires ("a recommended default that distorted branch lengths" is its own
  example) -- the audit already demonstrated it with a run before the fix pass started, and this
  re-audit reproduces it again independently. A one-line caveat would have been a cheap, in-scope
  correction. Kept as an open P2 in this report rather than escalated, since it does not block landing
  (no P0, no veto), but a future fix pass should treat it as demonstrated, not speculative.
- **"No multiple-testing correction guidance for genome-scale z-score GI calling" (Inputs 1, 5) --
  agree it is correctly out of scope.** No run, in either audit, has shown the documented cutoff
  producing a wrong call from multiple-testing inflation -- both the first audit's 200-pair run and
  this re-audit's 150-pair run recovered ground truth with 0 false positives at the stated z<-2/z>2
  cutoff. This is prospective best-practice advice (recommending BH correction as a hardening measure),
  not a correction of a demonstrated defect, so FIX_BRIEF's bar is not met. Correctly left open.
